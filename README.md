# YRCCS 2027 website

Draft website for the second Young Researchers Conference on Combinatorial Synergies,
Magdeburg, 31 May – 4 June 2027.

Organisers: Barbara Betti, Ansgar Freyer, Lakshmi Ramesh.

## How to view it

Download the repository (green **Code** button → **Download ZIP**), unzip it and
double-click `index.html`. The site opens in your browser; use the menu at the top right
to move between pages. Keep all files in the same folder.

## Pages

| File | Page |
|---|---|
| `index.html` | Home: about the conference, speakers, registration |
| `minicourses.html` | Minicourses |
| `programme.html` | Programme (timetable and activities) |
| `venue.html` | Venue, travel information, food options |
| `style.css` | Colours, fonts and layout for all pages |
| `theme.js` | Light / dark mode button |

## How to edit

Open a page in a text editor, search for `EDIT:` and change the text between the tags.
Comments and suggestions are welcome as GitHub issues.
